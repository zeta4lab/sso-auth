# sso-auth 문서 체계

이 저장소는 **문서를 먼저 확정하고 코드를 쓴다.**
순서는 `docs/` 작성 → 세부 논의로 결정 고정 → 구현이다.
결정되지 않은 항목은 코드로 먼저 정하지 않고 [논의 아젠다](discussion-agenda.md)에 남긴다.

## 문서

- [구조](architecture.md): 무엇을 Hydra에 맡기고 무엇을 직접 만드는가, 토큰 형태, 회전 방식, 가용성 절충.
- [논의 아젠다](discussion-agenda.md): 확정된 결정과 남은 열린 항목.

## 관련 프로젝트

zeta4c와는 **별개 프로젝트**다. zeta4c의 문서·규칙·로드맵을 이 저장소의 기준으로 끌어오지 않는다.
두 프로젝트가 연동될 경우에만 그 경계를 논의 아젠다에 명시한다.
